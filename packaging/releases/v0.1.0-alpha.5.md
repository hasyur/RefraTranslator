# RefraTranslator v0.1.0-alpha.5

Windows x64 Alpha 预发布版。下载本页附件 **RefraTranslator-Setup.exe**，双击并按照简体中文向导安装。安装包包含应用及图形界面运行环境；OCR 资源和翻译模型需按需单独准备。

## 本版改动

- 更新 Prism 工作台总览、导航和主题样式；将 Prism 与 Dohna 的工作台界面分开维护，Dohna 继续使用明亮配色。
- OCR 页面新增“鼠标触发”方式。默认鼠标停稳 300 毫秒后处理选定区域；识别区域继续使用动态 ROI 与现有翻译流程。也可以选用原生整区或动态 ROI 方式。
- 自定义识别区域按显示器比例保存，切换分辨率后自动换算。
- 调整连续画面的文字分组和批次翻译结果对应；改善日文长文本末尾内容的识别处理。
- 优化缓存命中结果的查找方式，并将错误纠正内容折叠显示。

## 安装与升级

支持 64 位 Windows 10/11。实时 OCR 需要支持 CUDA 的 NVIDIA 显卡及可用驱动。

1. 下载并运行本页附件 **RefraTranslator-Setup.exe**，选择本地可写的安装目录；需要桌面入口时勾选“创建桌面快捷方式”。
2. 从开始菜单、桌面快捷方式或安装目录中的 **RefraTranslator.exe** 启动程序。
3. 首次 OCR 准备需下载约 **3 GiB** 的运行依赖和识别模型；已有资源及缓存会扣除。完整准备过程目前约需 **13 GiB 可用磁盘空间**，包括下载、临时解包和安装，实际需求以程序检查为准。
4. 翻译模型在 **TRANSLATION / 翻译 → 下载并使用** 中单独准备。新配置默认使用内置的 **Hy-MT2 1.8B · Q8_0**；模型文件不包含在安装包中。

升级时先关闭 RefraTranslator，包括托盘中仍在运行的程序，再运行新版安装包并选择原安装目录。无需先卸载；配置、游戏档案、日志、模型和已准备的资源会保留。

安装包 SHA-256 校验值见附件 **SHA256SUMS.txt**。

本版仍是 Alpha：复杂动态场景可能出现漏译或延迟。鼠标触发会等待停稳和移动条件，因此也可能错过两次触发之间短暂显示的内容。降低 GPU 运行时间不代表翻译总是更快。
