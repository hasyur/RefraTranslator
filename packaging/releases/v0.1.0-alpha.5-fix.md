# RefraTranslator v0.1.0-alpha.5-fix

Windows x64 Alpha 预发布版。下载本页附件 **RefraTranslator-Setup.exe**，按简体中文向导安装。安装包包含应用和图形界面运行环境；OCR 资源和翻译模型仍需按需准备。

## 本版改动

- 修复已下载翻译模型无法复用的问题。应用会先检查本地模型文件的大小和 SHA-256；文件完整时，即使缺少校验标记也可通过本地校验恢复使用，无需重新下载。
- 调整 HTTPS 证书信任来源，使用 Windows 系统证书和 certifi 根证书，同时保留服务器证书与主机名校验。
- 安装向导会记住先前选择的安装目录，便于安装新版时继续使用原目录。
- 更新透明的 REFRA 可执行文件图标，并为任务栏运行图标使用棱镜图形。
- 在 alpha4 和 alpha5 原安装目录上的覆盖验证中，配置与资源均得以复用，程序正常启动；OCR 识别和本地模型翻译也已完成验证。

## 安装与升级

支持 64 位 Windows 10/11。实时 OCR 需要支持 CUDA 的 NVIDIA 显卡及可用驱动。

1. 下载并运行本页附件 **RefraTranslator-Setup.exe**，选择本地可写的安装目录；需要桌面入口时勾选“创建桌面快捷方式”。
2. 从开始菜单、桌面快捷方式或安装目录中的 **RefraTranslator.exe** 启动程序。
3. 首次 OCR 准备需下载约 **3 GiB** 的运行依赖和识别模型；已有资源及缓存会扣除。完整准备过程目前约需 **13 GiB 可用磁盘空间**，包括下载、临时解包和安装，实际需求以程序检查为准。
4. 翻译模型在 **TRANSLATION / 翻译 → 下载并使用** 中单独准备。新配置默认使用内置的 **Hy-MT2 1.8B · Q8_0**；模型文件不包含在安装包中。

升级时先关闭 RefraTranslator，包括托盘中仍在运行的程序，再运行新版安装包并选择原安装目录。无需先卸载；配置、游戏档案、日志、模型和已准备的资源会保留。

安装包 SHA-256 校验值见附件 **SHA256SUMS.txt**。

## 已知情况

- alpha4 覆盖安装后可能留下 27 个旧版界面文件。当前验证未发现其导致功能报错，旧文件清理尚未包含在本版中。
- HTTPS 证书校验已调整，但网络超时或下载服务不可用仍可能导致资源下载失败。
- 安装路径较长时，Windows 可能因目标文件完整路径限制而无法安装；遇到安装错误时，请选择较短的本地目录。
- 本版仍是 Alpha：复杂动态场景可能出现漏译或延迟。降低 GPU 运行时间不代表翻译总是更快。
