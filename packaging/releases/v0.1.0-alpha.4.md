# RefraTranslator v0.1.0-alpha.4

Windows x64 Alpha 预发布版。下载本页 Assets / 附件中的 **RefraTranslator-Setup.exe**（约 176 MiB），双击按中文向导安装。安装包自带 Python 和图形界面运行环境。

## 本版改动

- 安装、卸载向导默认使用简体中文。
- 修复首次 OCR 资源准备页在深色背景下标题、说明和下载文字不清楚的问题；文字适配深浅色背景，进度条更醒目。
- 增加**总下载进度条**，保留当前文件进度。总进度按所有待下载依赖和模型的字节累计，计入续传缓存；下载完成后明确提示仍需安装和校验。
- 新安装默认使用**内置本地模型（CUDA）**，预设为 **Hy-MT2 1.8B · Q8_0**；按该默认配置新建的游戏档案沿用此预设。升级时已有配置的翻译后端和模型选择保留。
- README 以 EXE 安装为推荐流程，新增发布下载入口，补充首次资源准备、磁盘需求和覆盖更新说明；源码开发步骤移到可选章节。

## 安装与升级

支持 64 位 Windows 10/11。实时 OCR 需要支持 CUDA 的 NVIDIA 显卡及可用驱动。

1. 下载并运行 **RefraTranslator-Setup.exe**，选择本地可写的安装目录；需要桌面入口时勾选“创建桌面快捷方式”。
2. 从开始菜单、已创建的桌面快捷方式或安装目录的 **RefraTranslator.exe** 打开程序。
3. 首次 OCR 准备需额外下载约 **3 GiB**；已有资源与缓存会扣除。完整准备过程目前约需 **13 GiB 可用磁盘空间**，包含下载、临时解包和安装，以程序的实际检查结果为准。
4. 内置翻译模型仍在 **TRANSLATION / 翻译 → 下载并使用** 单独准备，不包含在首次 OCR 资源下载中。

升级时先关闭 RefraTranslator，包括托盘中仍在运行的程序，再运行新版安装包并**选择原安装目录**。无需先卸载；配置、游戏档案、日志、模型和已准备资源会保留。数据和日志继续位于安装目录，启动日志为 `output\launcher.log`。

从 `v0.1.0-alpha.1` 或 `alpha.2` 升级的旧用户，可按 README 的“数据位置与迁移”说明手动沿用旧用户目录数据。

安装包 SHA-256 校验值见附件 **SHA256SUMS.txt**。发布源码提交：`1172aab2a8efd2862670dc0644d8c4e886838492`。
